How to build UI heredocs/agents/design-system.md — the full constitution
  1. Compose before creating. Reuse order: components/ui/* (shadcn) → components/widgets/_kit.tsx → components/common/* → feature-local → custom. New shared components need 3+ real consumers.
  2. Semantic tokens only. Colours come from var(--bg-*/--text-*/--border-*/--icon-*) — never raw hex, never primitives in components. Exceptions: team/token brand colours and chart data colours.
  3. Real interactive elements. Button/Link/Input, never clickable divs. Toggles expose aria-pressed; icon-only buttons need aria-label.
  4. SSR-safe. No Date.now()/Math.random()/unpinned locale in render — use the kit's rng/seedFrom and "en-US".
  5. No silent exceptions. Intentional bypasses ship with an explicit DESIGN SYSTEM EXCEPTION block.
